# Результаты проверки BookNest

## Проверка HTML

Для проверки HTML-разметки использовался W3C HTML Checker.

Проверялись три страницы проекта:
- `index.html` — каталог книг.
- `book.html` — страница с подробной информацией о книге.
- `loan.html` — форма заказа книги.

Результаты проверок сохранены в скриншотах.

## Проверка доступности

Для оценки доступности использовался Lighthouse.

Страница `index.html` получила 96 баллов из 100 в категории Accessibility.

Результаты проверки остальных страниц будут добавлены после проведения аудита.

## Скриншоты

Скриншоты проверок HTML и Lighthouse хранятся в папке `docs/lab1`.
