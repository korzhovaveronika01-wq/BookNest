# Структура проекта BookNest

## Назначение проекта

BookNest — учебный сайт книжного магазина, состоящий из трёх HTML-страниц. Проект разработан с использованием семантической разметки HTML без CSS.

## Страницы проекта

### index.html — каталог книг

Главная страница содержит список книг, информацию об авторах и краткие описания. Используются семантические элементы `header`, `nav`, `main`, `article`, `section`, `aside` и `footer`.

### book.html — информация о книге

Страница содержит подробную информацию о книге «Дюна», её описание, характеристики и отзывы. Используются элементы `figure`, `time` и `dl`, а также микроразметка Schema.org типа `Book`.

### loan.html — форма заказа книги

Страница предназначена для оформления заявки на получение книги. Форма содержит поля для данных читателя, выбора книги, указания срока и дополнительных сведений. Используются `form`, `fieldset`, `legend` и `label`, а также встроенные средства проверки введённых данных.

## Общие требования

- Язык документа — русский (`lang="ru"`).
- У каждой страницы есть заголовок первого уровня `h1`.
- Для изображений предусмотрены альтернативные описания `alt`.
- Для навигации между страницами используются HTML-ссылки.
- Стили CSS не используются в соответствии с условиями задания.
